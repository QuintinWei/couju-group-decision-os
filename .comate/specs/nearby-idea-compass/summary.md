# 附近灵感罗盘：实现总结

## 完成内容

本次改造已完成并覆盖创建页、候选召回、定位服务、测试和产品文档：

- 删除创建页说明卡中的“划卡后，换一批会参考你的真实反馈。”，保留“随机，但不是乱推”和其他实际能力说明。
- 聚餐兴趣新增“东北菜”“川湘菜”“江西菜”“东南亚菜”，并将“云南菜”统一改为“云贵菜”。
- 为新增菜系和云贵菜补充演示候选，实时高德模式使用对应兴趣关键词召回。
- 周末活动增加展示名称为“景点”的兴趣和演示候选。
- 移除活动 POI 的景点特殊过滤；景点与普通活动统一使用跨类别分桶轮询和数量控制，避免整批结果被单一类别占满。
- 修正演示模式的 focused 回退：有匹配的主动兴趣时优先返回匹配候选，不再因为数量不足强行混入无关类型。
- 定位成功后通过高德逆地理结果识别六个支持城市，并自动同步创建页城市下拉框；自动切城不会清除刚取得的坐标。
- 高德 Key 缺失、逆地理请求失败或超时时保留降低精度后的有效坐标，并使用“当前位置附近”兜底，不伪造城市归属。
- 区分浏览器定位权限拒绝、系统不可用、请求超时和未知错误，加入房间页也使用可操作的错误提示。
- 同步更新 README 和 AI 工作流文档，移除过期的景点过滤和云南菜描述。

## 行为边界

- 自动切换城市仅针对上海、北京、深圳、杭州、成都、广州六个已支持城市。
- 浏览器没有授权、系统定位关闭或设备无法取得位置时，仍需用户重试或手动输入地铁站/商圈。
- 无法识别支持城市时保留当前城市，但继续使用有效的附近坐标。
- 坐标用于附近优先和通勤估算，不代表实时公交、驾车路线或精确到店距离。
