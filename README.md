## 作品简介

凑局是一款面向朋友聚餐和周末活动的 AI 群体决策产品。它不让房主替所有人做选择，也不简单统计多数票，而是让每位成员分别提交时间、预算、出发地、通勤上限和个人反馈，再从真实地点中找到共同可行的方案。

```text
创建房间 → 邀请好友 → 全员提交空闲时间和个人边界
→ 生成多人可达的共享卡池 → 独立滑卡
→ 共同底线过滤 → 公平排序 → 锁定行动方案
```

## 如何体验

1. 打开 [在线 Demo](https://couju-demo.quintinwei1314.chatgpt.site/)，选择「一起吃饭」或「出去玩」。
2. 填写城市、日期范围、大概时段、预计时长、出发地和目标人数。
3. 复制房间链接，让好友从另一台设备或浏览器加入。
4. 每位成员提交自己的空闲时间、预算和单程通勤上限。
5. 全员到齐后，系统生成 12 张每个人都在通勤范围内的共享候选卡。
6. 所有人独立选择「喜欢 / 还行 / 不喜欢」，彼此不会被提前带节奏。
7. 系统排除任何成员明确拒绝或不满足硬约束的地点，给出一个群体最优结果。
8. 如果本轮没有交集，可以根据全体反馈进入下一轮探索；最多支持三轮。

## 已实现的产品能力

### 多人协作

- 2–6 人持久化房间，可通过链接跨设备加入；
- 每位成员拥有独立身份和选择记录，房间自动同步进度；
- 目标人数全部加入并提交后，房主才能开始计算或推进下一轮；
- 仅凭房间号不会公开成员昵称、具体空闲时间和个人选择。

### 时间与地点交集

- 房主设置日期范围、上午 / 下午 / 晚上倾向和预计活动时长；
- 成员可填写一段或多段具体空闲时间；
- 服务端计算全员共同时间，交集不足时不会伪造结果；
- 出发地支持手输地铁站、商圈或浏览器授权定位；
- 候选按每位成员各自的通勤上限筛选，不只以房主位置为中心。

### 真实候选与多样性

- 通过高德地点搜索获取 POI 名称、地址、坐标、照片、评分和可用价格信息；
- 支持上海、北京、广州、深圳、杭州、成都、南京、重庆、苏州、合肥；
- 聚餐覆盖多种菜系，活动覆盖电影、攀岩、陶艺、KTV、剧本杀、棋牌、按摩及景点等类型；
- 同一轮按 POI ID 去重，并控制类别分布，避免卡池被单一类型占满；
- 未配置高德 Key 或接口失败时，使用明确标记的演示候选保证流程可体验。

### 多轮反馈

- 每轮 12 张共享卡，所有成员评价同一批候选；
- 喜欢、还行和不喜欢会影响下一轮类别权重；
- 全部拒绝本轮卡片的成员可获得 3 张私人发现卡，并最多提名 1 张进入下一轮共享评价；
- 下一轮保留反馈学习结果，同时安排新类型探索；
- 第三轮仍无可行结果时展示冲突原因，不强行生成答案。

## AI 在哪里

DeepSeek 用来理解低成本、非结构化的人类表达，并把反馈变成可计算的信息；确定性算法负责最终过滤和排序。

| 环节 | AI / 算法的作用 |
|---|---|
| 偏好理解 | DeepSeek 将补充描述整理为可确认的结构化标签 |
| 反馈学习 | 汇总喜欢、还行、拒绝及拒绝原因，调整下一轮类别倾向 |
| 冲突解释 | 把预算、通勤、时间或共同偏好冲突解释成易懂语言 |
| 结果说明 | 为确定性算法已经选出的结果生成推荐理由 |
| 最终决策 | FairMix 执行硬约束过滤、最低满意度保护、Pareto 与 Nash 排序 |

语言模型不会虚构地点，也不能绕过成员的预算、通勤、时间和明确拒绝。

## 推荐与排序逻辑

候选首先经过共同底线过滤：任意成员明确拒绝、超出已知预算、超过通勤上限或无法满足共同活动时长时，该候选不会进入最终排序。

剩余候选根据三类群体指标排序：

- **最低满意度**：优先保护最不满意的成员；
- **Nash 群体福利**：避免用多数人的高分掩盖少数人的低分；
- **平均效用**：在满足公平底线后比较整体体验。

高德评分只作为地点质量信号之一，不直接决定最终结果。`Group Fit` 是当前房间内部的相对排序分数，不代表成功概率。

## 数据来源与边界

- 地点事实来自高德地点搜索，通勤时间目前根据成员与候选坐标进行估算；
- 只有高德返回可用人均价格且不超过所有成员预算的候选，才会进入共享卡池；
- DeepSeek 服务不可用时，偏好理解与结果说明会使用规则降级；
- 当前未接入美团 / 大众点评、商户订座和实时公交 / 驾车路线矩阵；
- 地点营业、价格及可预约状态应在最终出发前再次确认。

## 技术实现

- React 19 + TypeScript
- Vinext + Cloudflare Runtime
- Cloudflare D1 多人房间持久化
- DeepSeek Chat Completions
- 高德地点搜索 2.0 与地理编码
- 原生 CSS 响应式界面
- Node Test 与生产构建验证

主要模块：

```text
app/page.tsx                         完整交互流程与多人状态
app/api/candidates/                  高德候选召回与演示回退
app/api/members/                     成员加入、边界和反馈提交
app/api/rooms/                       房间创建与同步
app/api/rounds/                      私人发现与多轮推进
app/api/preferences/                 DeepSeek 偏好结构化
app/api/explain/                     结果与冲突解释
lib/group-candidate-intersection.ts  多人通勤交集
lib/rounds.ts                        多轮反馈与候选组成
lib/couju.ts                         FairMix 过滤与排序
db/                                  D1 数据结构
tests/                               核心逻辑与页面验证
```

## 本地运行

需要 Node.js `>= 22.13.0`。

```bash
npm install
npm run dev
```

可选服务端配置：

```text
DEEPSEEK_API_KEY=
DEEPSEEK_API_BASE=https://api.deepseek.com
DEEPSEEK_MODEL=
DEEPSEEK_TIMEOUT_MS=45000
AMAP_WEB_SERVICE_KEY=
```

验证项目：

```bash
npm run build
npm test
```
