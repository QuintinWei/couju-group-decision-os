## 这是什么

凑局是一款面向 2–6 人聚餐与活动场景的 AI 群体决策产品。

当朋友们的时间、位置、通勤上限、预算和兴趣不同时，普通投票只会统计票数；凑局会先找到所有成员都可接受的候选，再用公平算法选出一个结果，并解释为什么。

它解决的不是“哪里评分最高”，而是：

- 大家什么时候都有空；
- 哪些地点每个人都能到达；
- 哪些候选没有触碰任何人的底线；
- 如果没有交集，分歧到底在哪里；
- 下一轮应该如何根据全体反馈改变。

## 当前产品闭环

```text
创建房间 → 分享链接 → 全员加入
→ 提交空闲时间与个人选择边界
→ 生成多人共同可达的 12 张共享卡
→ 每位成员独立选择喜欢 / 一般 / 不喜欢
→ 有交集：FairMix 计算唯一群体最优解
→ 无交集：AI 诊断分歧 + 每人 3 张私人发现卡
→ 汇总成员提名、反馈学习与新类型探索
→ 进入下一轮共享评选
→ 锁定地点、打开地图或加入日历
```

私人发现卡不会直接成为结果。每个人最多提名一张，也可以跳过；提名进入下一轮后，仍需所有成员共同评价。

## AI 在哪里

凑局没有把最终决定交给大模型“凭感觉”生成。DeepSeek 和确定性算法各自负责适合自己的部分：

| 能力 | 实现 | 作用 |
|---|---|---|
| 反馈理解 | DeepSeek + 安全降级 | 汇总群体喜欢、拒绝及原因，生成“AI 学到了什么” |
| 冲突解释 | DeepSeek + 可复现诊断 | 在无交集时解释主要分歧，不伪造可行结果 |
| 结果解释 | DeepSeek + 证据约束 | 将算法分数转成人能理解的推荐理由，无权改变名次 |
| 可行性过滤 | 确定性规则 | 检查时间、预算、通勤和明确拒绝等边界 |
| 群体排序 | FairMix | 结合最低满意度、Nash 福利、平均效用与 Pareto 前沿 |

DeepSeek 不负责创造餐厅、活动、价格或路线事实；地点候选来自高德，排序结果由代码计算。AI 服务异常时，产品会使用确定性总结继续运行，不会卡住多人流程。

## 推荐不是“高分店排行榜”

首轮候选会从不同类别中召回并去重，再根据每位成员自己的出发位置和通勤上限求共同可达范围。高德评分只作为地点质量参考，不直接决定最终结果。

进入排序前，系统会排除违反成员硬边界的候选。对剩余候选，FairMix 优先保护群体中满意度最低的人，再比较整体福利：

```text
存在最低满意度 ≥ 60 的候选：
Score = 0.35 × 最低满意度 + 0.55 × Nash 几何均值 + 0.10 × 平均满意度

否则：
Score = 0.65 × 最低满意度 + 0.25 × Nash 几何均值 + 0.10 × 平均满意度
```

`Group Fit` 是当前房间内部的相对排序分，不代表成功概率。

## 多轮反馈学习

- 每轮所有成员评价同一批 12 张共享卡。
- 喜欢、一般、不喜欢及拒绝原因会改变下一轮候选构成。
- 无共同结果时，每位成员可查看 3 张仅自己可见的私人发现卡。
- 下一轮由成员提名、群体反馈学习和 4 张新类型探索组成。
- 所有私人提名必须重新进入共享卡池，不能绕过群体评价。
- 最多进行 3 轮；仍无解时展示冲突来源与可调整边界，不强行生成结果。

## 可交互能力

- 支持上海、北京、广州、深圳、杭州、成都、南京、重庆、苏州、合肥；
- 聚餐与周末活动两套候选链路；
- 日期范围、上午 / 下午 / 晚上、预计时长和多人空闲时间交集；
- 浏览器定位或手动输入地铁站、商圈；
- 每位成员独立设置预算、单程通勤上限和场景偏好；
- 高德 POI、地址、坐标和地点图片；
- 12 张共享卡、拒绝原因、私人发现与最多三轮反馈学习；
- DeepSeek 群体反馈总结、冲突解释和最终推荐解释；
- 唯一群体结果、成员满意度、地图跳转和 `.ics` 日历文件；
- 可公开分享的持久化多人房间与跨设备同步；
- 桌面端与移动端 H5 响应式体验。

## 数据边界

- 配置 `AMAP_WEB_SERVICE_KEY` 时使用高德真实 POI；接口不可用时切换到明确标识的演示候选。
- 高德地点信息不等于实时可订、实时价格或实时营业状态，行动前仍需确认。
- 当前通勤使用成员坐标与候选坐标估算，尚未接入实时公交 / 驾车路线矩阵。
- 当前未接入美团、大众点评及商户订座接口。
- DeepSeek 只接收完成任务所需的聚合信息；AI 结果不能绕过确定性硬约束。

## 隐私设计

- 无需注册，通过随机房间号和设备成员令牌参与；
- 仅凭房间号看不到成员昵称、出发地和私人选择；
- 其他成员只能看到私人发现是否完成及匿名提名总数，看不到私人卡内容；
- 系统定位仅在用户主动点击并授权后调用；
- 服务端只保存成员令牌哈希，AI 接口调用前验证成员身份。

## 本地运行

要求 Node.js `>= 22.13.0`。

```bash
npm install
npm run dev
```

可选服务端环境变量：

```text
DEEPSEEK_API_KEY=
DEEPSEEK_API_BASE=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_TIMEOUT_MS=45000
AMAP_WEB_SERVICE_KEY=
```

验证项目：

```bash
npm test
```
