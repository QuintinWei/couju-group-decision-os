# 凑局 Couju

> 帮一群人从“都行”走到一个真正能执行的共同决定。

[在线体验](https://couju-demo.quintinwei1314.chatgpt.site/) · [演示视频](https://github.com/user-attachments/assets/7b5fe9cf-3378-4757-99ac-128d2a0ed951)

凑局是一款面向 2–6 人聚餐与活动场景的 AI 群体决策产品。它不只统计谁投了几票，而是把每个人的时间、位置、预算、通勤边界和真实反馈放进同一套决策流程，找到所有成员都能接受的唯一结果。

## 现在可以体验什么

```text
选择吃饭 / 玩乐 → 创建并分享房间 → 全员提交空闲时间和选择边界
→ 生成 12 张多人共同可达卡片 → 独立评价 → 得到唯一结果
→ 若没有交集：AI 解释分歧 → 每人查看 3 张私人发现卡并可提名 1 张
→ 提名与学习后的新候选进入下一轮共享评价（最多 3 轮）
```

- 支持上海、北京、广州、深圳、杭州、成都、南京、重庆、苏州、合肥；
- 聚餐与玩乐两套候选体系，玩乐覆盖电影、攀岩、陶艺、KTV、剧本杀、麻将、按摩等类别；
- 日期范围、上午 / 下午 / 晚上、预计时长与多人空闲时间交集；
- 浏览器定位或手动输入地铁站、商圈；
- 每位成员独立设置人均预算、单程通勤上限和场景偏好；
- 高德真实 POI、地址、坐标、图片与地图跳转；
- DeepSeek 群体反馈学习、冲突解释和结果解释；
- 私人发现卡、成员提名、最多三轮共同决策；
- 唯一群体结果、成员满意度和日历文件；
- 公开房间链接、跨设备同步、桌面端与移动端 H5。

## AI 不只是抽取字段

DeepSeek 负责理解人类表达和群体反馈：

1. 将自然语言补充整理为可确认的偏好；
2. 汇总一轮中“喜欢 / 一般 / 不喜欢”及拒绝原因，形成下一轮偏好变化；
3. 在没有交集时解释主要冲突，并给出可验证的边界调整建议；
4. 把最终算法结果解释成人能理解的推荐理由。

地点事实来自高德，硬约束过滤和最终名次由确定性代码完成。大模型不能创造餐厅、价格或位置，也不能绕过任何成员的预算与通勤底线。AI 接口不可用时，流程会使用规则总结继续运行。

## 推荐与最终算分

候选先按类别召回并去重，再检查每位成员的预算和通勤上限。只有满足所有成员硬边界的候选才能进入共同卡池。高德评分是质量参考，不是最终排名。

对可行候选，FairMix 优先保护群体中体验最差的人，再比较整体福利：

```text
有候选的最低满意度 ≥ 60：
Score = 0.35 × 最低满意度 + 0.55 × Nash 几何均值 + 0.10 × 平均满意度

否则：
Score = 0.65 × 最低满意度 + 0.25 × Nash 几何均值 + 0.10 × 平均满意度
```

`Group Fit` 是当前房间内的相对排序分，不是成功概率。

## 数据从哪里来、存在哪里

- 地点候选：高德 Web 服务 API；不可用时会明确切换到演示候选；
- AI 理解：DeepSeek 官方 API；
- 房间、成员、时间范围、选择边界和轮次反馈：Cloudflare D1；
- 成员身份：浏览器只保存当前设备的成员凭证，服务端仅保存凭证哈希；
- 页面与接口：部署在 OpenAI Sites / Cloudflare Runtime。

当前通勤时间由成员与候选的坐标距离估算，不代表实时公交或驾车时间。高德 POI 也不等于实时可订、实时价格或实时营业状态。

## 隐私边界

- 无需注册，通过随机房间号和设备成员凭证参与；
- 只知道房间号无法读取成员昵称、出发地与私人选择；
- 私人发现卡只有本人可见，其他成员只看到匿名提名数量；
- 系统定位只在用户主动点击并授权后触发；
- 发送给 DeepSeek 的内容会先去除昵称、具体出发地和成员凭证。

## 本地运行

Node.js `>= 22.13.0`：

```bash
npm install
npm run dev
```

环境变量：

```text
DEEPSEEK_API_KEY=
DEEPSEEK_API_BASE=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-v4-flash
DEEPSEEK_TIMEOUT_MS=45000
AMAP_WEB_SERVICE_KEY=
```

验证：

```bash
npm test
npm run build
```

## 技术结构

- Next.js / React 19 / TypeScript
- Vinext + Cloudflare Runtime
- Cloudflare D1
- DeepSeek Chat Completions JSON Output
- 高德地理编码与地点搜索
- 原生 CSS 响应式界面
- Node Test 回归测试

这是一个公开可体验的 AI 产品 Demo。它重点验证：AI 如何理解多人反馈，并与可测试、可复现的公平决策算法协作。
